# Dataset attribution

`ENB2012_data.xlsx` is the unmodified workbook distributed by the UCI Machine Learning Repository.

Tsanas, A. & Xifara, A. (2012). *Energy Efficiency* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C51307.

- Source: https://archive.ics.uci.edu/dataset/242/energy+efficiency
- Download: https://archive.ics.uci.edu/static/public/242/energy+efficiency.zip
- License: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
- 768 simulated designs, eight features, and two targets. This project uses only Y1 (heating load); Y2 is never a model input.
- The data describe Ecotect simulations, not measured utility bills. No real-building deployment claim is made.

The experiment records the workbook SHA-256 in `results/summary.json`.
